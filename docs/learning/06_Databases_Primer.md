# 06 - Database Primer (Optional)

This project does not use a database yet.

What a DB would do
- Store chats, users, contracts, settings.
- Allow querying and history across devices.

Where it would live
- Backend only (FastAPI).
- Frontend talks to backend endpoints.

What would change
- Add a DB client in Python.
- Create new endpoints (save/load chats).
- Update UI to call those endpoints.
